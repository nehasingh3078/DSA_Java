# Java DSA Practice

A collection of **Data Structures and Algorithms (DSA) problems solved in Java** for interview preparation and strengthening problem-solving skills.

## 📚 Topics Covered

### 🔢 Numbers

* Reverse a number
* Palindrome number
* Prime number
* Factorial
* Fibonacci series
* Armstrong number
* Even and odd numbers
* Sum of digits

### 🔤 Strings

* Reverse a string
* Palindrome string
* Character frequency
* First non-repeating character
* Anagram
* Longest word
* Longest substring without repeating characters
* Count vowels and consonants

### 📦 Arrays

* Find maximum and minimum
* Reverse an array
* Remove duplicates
* Move zeroes
* Missing number
* Two Sum
* Binary Search
* Stock Buy and Sell
* Kth missing positive number
* Product of array except self
* Merge intervals

### 🔗 Linked List

* Reverse linked list
* Find middle element
* Detect cycle
* Merge two sorted linked lists

### 🗺️ HashMap / HashSet

* Frequency counting
* Duplicate elements
* Two Sum
* Character and word counting

### 🥞 Stack / Queue

* Valid parentheses
* Stack operations
* Queue operations

## 🛠️ Technology

* **Java**
* **JDK 17+**
* VS Code / IntelliJ IDEA

## 🎯 Goal

The goal of this repository is to:

* Practice Java programming fundamentals
* Improve problem-solving skills

* Prepare for SDET / QA Automation / Software Engineering interviews
* Write clean and readable Java code

## ▶️ How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd DSA_Java
```

Compile a Java file:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```
